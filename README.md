# Diagrama del Proceso de Compras 📋

Página web que muestra el **diagrama de flujo del proceso de compras** de una empresa, dibujado con **Mermaid**: desde el requerimiento de materiales hasta la adquisición y el seguimiento de la entrega.

## 🔄 Etapas

1. **Requerimiento**: elaboración y aprobación del requerimiento de materiales
2. **Evaluación y selección**: evaluación de propuestas, selección de proveedores, negociación y contratación
3. **Adquisición**: orden de compra, distribución y seguimiento de entrega

## 🛠️ Stack

- **HTML** + **Mermaid**
- Desplegado con **Firebase Hosting**

El diagrama en texto está en [`diagrama-compras.md`](diagrama-compras.md).
